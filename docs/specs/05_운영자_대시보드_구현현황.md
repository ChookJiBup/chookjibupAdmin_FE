## 1. 이번 세션에서 한 일

경로: `src/features/dashboard/`, `src/app/console/festivals/[festivalId]/operator-dashboard/`

1. **지도가 아예 렌더링되지 않던 버그 수정** — `Map` 컨테이너에 `h-full w-full`을 쓰면 상위 요소들의 `height: 100%` 연쇄가 어딘가에서 `auto`로 끊겨 실제 렌더 높이가 0이 되는 문제가 있었다. `absolute inset-0`으로 대체해 해결했다.
2. **지도가 다른 UI를 가리던 버그 수정** — 카카오맵 내부 레이어가 `z-index: 1`을 쓰는데, 우리 쪽 wrapper들이 스태킹 컨텍스트를 안 만들어서 그 값이 루트 컨텍스트까지 새어나가 사이드바·버튼·통계바를 덮어버렸다. 지도 컨테이너에 `isolate`를 줘서 해결했다.
3. **줌 레벨이 이상하게 깨지던 버그 수정** — 설치된 `react-kakao-maps-sdk`(v1.2.1)가 `minLevel`/`maxLevel` prop을 서로 뒤바꿔 `kakao.maps.Map.setMinLevel`/`setMaxLevel`에 전달하는 버그가 있다. 해당 prop 대신 `onCreate`에서 직접 정확한 인자로 호출하도록 우회했다.
4. **지도 풀블리드 레이아웃** — `consoleUiStore`에 `fullBleed` 플래그를 추가하고 콘솔 레이아웃(`src/app/console/layout.tsx`)이 이를 읽어, 대시보드 화면에서는 네비바 바로 아래부터 화면 전체를 지도가 채우도록 좌우/상하 여백을 없앴다. 다른 화면은 기존 여백 레이아웃 그대로다.
5. **혼잡도/아이콘 색상 정리** — "여유"를 회색 대신 파랑(`primary`)으로 통일(배지·지도 마커 모두), 부스 목록 아이콘을 모니터 아이콘(`DesktopIcon`)으로, 선택된 부스는 타겟 아이콘(`TargetIcon`)으로 구분. "수정하기" 버튼도 공통 `Button`의 `primary` variant로 통일. 부스 목록 스크롤바는 시각적으로 숨김.
6. **AI 제안 UI 교체** — 우측 하단에 쌓이던 sonner 토스트 대신, 지도 위 좌상단에 고정 카드로 노출하고(경고 아이콘 + 제목 + 설명 + 닫기 버튼), 제안과 관련된 경로를 지도 위 폴리라인(`Polyline`)으로 함께 그리도록 바꿨다. 카드를 닫으면 경로선도 같이 사라진다. `AiSuggestion` 타입에 `path` 필드를 추가했다.
7. **운영자/총괄관리자 대시보드 경로 분리** — 지금까지 총괄관리자(`FESTIVAL_OWNER`)와 운영자(`SUB_ADMIN`)가 같은 `/console/festivals/[festivalId]/dashboard`를 공유했는데, 이 지도 대시보드는 운영자 전용 화면이므로 `/console/festivals/[festivalId]/operator-dashboard`로 옮겼다. 총괄관리자의 `/dashboard`는 화면이 아직 정해지지 않아 빈 페이지(`return null`)로 남겨뒀다. `Nav.tsx`, `HomeFestivalBoard.tsx`의 관련 링크도 함께 수정.

## 2. 아직 안 한 것 / 다음에 할 일

- [ ] **총괄관리자용 대시보드 화면 설계** — 지금은 완전히 빈 페이지다. 총괄관리자에게 무엇을 보여줄지(운영자 대시보드와 같은 지도? 축제 전체 통계? 운영자 목록 요약?) 기획이 필요하다.
- [ ] **실제 API 연동** — 부스 위치(`lat`/`lng`), 혼잡도, 대기시간, 줄끝 갱신자, AI 제안 전부 `mockData.ts` 목업이다. `04_부스맵_에디터_결과보고.md`에 정리된 것처럼 백엔드에 부스 좌표 컬럼이 아직 없어서, 실제 좌표 기반 API가 나오기 전까지는 목업을 유지해야 한다.
- [ ] **AI 제안 로직 자체가 없음** — 프론트는 "제안이 오면 카드+경로선으로 보여주는" 화면만 구현했을 뿐, 혼잡도를 분석해 제안을 만드는 백엔드/AI 로직은 없다(`04_부스맵_에디터_결과보고.md` 5번 항목과 동일한 이슈).
- [ ] **줄끝 갱신 API 연동** — `DashboardStatsBar`의 "줄끝 갱신하기"는 현재 400ms 딜레이만 주는 `mockUpdateQueueTail`이다.
- [ ] **부스 좌표를 위/경도(lat/lng)로 쓰는 것이 맞는지 재검토** — 부스맵 에디터(`src/features/boothmap/`)는 캔버스 픽셀 좌표(x/y) 기반인데, 이 실시간 대시보드는 카카오맵 위/경도 기반으로 별도 구현되어 있다. 실제 축제 부지는 GPS 좌표로 표현하는 게 맞겠지만, 부스맵 에디터와 좌표계가 다르다는 점은 백엔드 좌표 컬럼 설계 시(`04_부스맵_에디터_결과보고.md` 1번 요청) 함께 고려해야 한다.
- [ ] **`react-kakao-maps-sdk`의 minLevel/maxLevel 버그**는 라이브러리 자체 버그라 `onCreate` 우회로 막아뒀다. 라이브러리가 업데이트되면 우회 코드를 제거할 수 있는지 확인.
